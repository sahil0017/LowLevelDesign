Object-oriented **Low-Level Design (LLD)** implementations in Java focusing on clean entity modeling, service boundaries, enums, and state transitions.

## Included Modules (`src/main/java/com/system_design/lld/`)

- **Online Assessment Platform (`Allen/`)**: Users, roles, multi-stage tests, questions, and test-simulation workflows.
- **Bank Management & ATM (`BankAccountApp/`, `BankManagementSystem/`)**: Account operations and ATM interaction modeling.
- **Entity Associations (`Association/`)**: User and group relationship modeling.

## Build & Run

```bash
./mvnw test
```
